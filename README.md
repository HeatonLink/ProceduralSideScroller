# Procedural Side Scroller

High-quality HTML5 canvas side-scroller using **procedural skeletal rigging** for all characters instead of pixel sprite sheets.

All limbs, torsos, and heads are drawn in real time from bone angles and lengths. Walk, idle, jump, and attack cycles are generated by joint angle functions.

Open `index.html` in a browser.

## Controls
- A / D or Left / Right: move
- Space or Up: jump (coyote time + jump buffer)
- J: attack

## Features
- Procedural character and enemy rigs
- Smooth walk / idle / jump / attack animations
- Platforming with gaps
- Patrol enemies
- Particles, camera follow, health, score
- Clean modular JS
- **Per-character rig folders** (`js/characters/`) that default to the built-in humanoid if the file is empty or missing a custom maker

## Custom character rigs
Put overrides in `js/characters/<name>.js` (loaded after `js/rig.js`).  
Example (player):
```js
G.rigMakers.player = function (scale) {
  const rig = G.makeHuman(scale);
  // tweak or rebuild the bone tree
  return rig;
};
```
If no `G.rigMakers[name]` is set, `G.makeRig(name, scale)` falls back to `G.makeHuman`.

Inspired by [BonkySideScroller](https://github.com/HeatonLink/BonkySideScroller).
